# Transfermarkt Data Analysis: Top 5 Transfer Networks

In this project, we analyze the Network of player transfers between clubs of the five top European leagues (Premier League, La Liga, Serie A, Bundesliga, Ligue 1), from July 2013 to July 2026. 

## Setup

To prepare your setup for this project run this command in your terminal:

pip install -r requirements.txt

## Data

The data is saved in this repository. It comes from a Transfermarkt dataset found on Kaggle: https://www.kaggle.com/datasets/davidcariboo/player-scores/data

Create a folder named `Data` in the repository and place the files found on the link above in it.
